草记 隐私政策

生效日期：2026 年 10 月 22 日　|　适用版本：草记 Android 客户端
一句话说清：草记默认只在你的手机上处理和保存录音与文字， 不向我们的任何服务器发送。只有当你自己配置了第三方语音转写或大模型接口后， 处理某条记录时的那一段音频或文本才会发送到你指定的那家服务商。

一、我们处理哪些信息

信息类型内容与用途
录音音频 由你主动开始记录，或连接蓝牙耳机后自动开始录制。用于本地转写与生成摘要。 默认在转写完成后删除原音（可在设置中选择保留）。
转写文本、摘要、待办、项目归类、洞察 由录音转写与你在应用中手动编辑产生，用于「今日」「项目」「觉察」等页面的展示与提醒。
应用配置 你填写的接口地址、模型名、API Key，以及声纹模板、提醒时间等设置项。
运行日志（仅本机） 程序异常时写入应用私有目录的一小段错误堆栈，用于定位崩溃原因，不含录音与转写正文。

我们不收集：手机号、通讯录、短信、精确位置、设备识别码（IMEI / OAID / Android ID）、 已安装应用列表、剪贴板内容，也不含任何广告或统计分析 SDK。

二、信息保存在哪里

  • 录音、转写、摘要、待办与配置，全部保存在应用私有目录（Android 沙箱），其他应用无法读取。
  • API Key 与声纹模板使用 Android 系统密钥库（Keystore） 中的 AES-256-GCM 密钥加密后存储； 该密钥由系统托管、不可导出，也不随任何备份迁移。
  • 本应用已关闭云备份与换机克隆，私人录音不会被系统复制到云端或另一台设备。
  • 卸载应用即删除上述全部数据（包括密钥材料）。

三、什么时候会联网

以下动作只在你主动配置并触发时发生，且目标地址是你自己填写的第三方接口：

  • 语音转写：把该条记录的音频文件发送给你配置的转写服务（如硅基流动 SenseVoice）。
  • 摘要 / 待办 / 洞察 / 复盘：把该条记录的转写文本发送给你配置的大模型服务。
  • 连通性测试：在设置页点击「测试连接」时，发送一次极短请求以验证地址与 Key 是否可用。

接口地址强制使用 https，明文 HTTP 请求会被应用直接拒绝。 数据到达上述服务商后，其处理行为受该服务商自己的隐私政策约束，请你自行了解并选择可信的服务商。

四、权限与用途

权限用途
麦克风（RECORD_AUDIO）录制你要记录的对话与语音速记。仅在你开始记录时使用。
蓝牙（BLUETOOTH_CONNECT 等）检测蓝牙耳机连接状态，实现「戴上耳机自动开始记录、摘下自动结束」。
通知（POST_NOTIFICATIONS）显示录音进行中的常驻通知与待办到期提醒。
音频/媒体读取（READ_MEDIA_AUDIO）仅在你点击「扫描系统通话录音并导入」时读取手机自带的通话录音文件，用于事后补录。不会后台扫描。
日历读写（READ/WRITE_CALENDAR）仅在你点击「同步待办到系统日历」时写入全天日程。单条加入日历通过系统日历的「新建日程」界面完成，不需要该权限。

所有权限均在系统弹窗中由你逐项授权，拒绝不影响其他功能使用。

五、录音的合规提醒

重要：记录他人对话前，请确认你已取得对话各方的同意，或该录音具有其他合法依据。 草记只提供技术能力，无法替你取得他人同意。因未取得同意而录音、传播所引发的法律责任，由使用者自行承担。

六、你的权利

  • 查看与修改：任意记录的摘要可直接编辑；说话人可改名；待办可改到期日。
  • 导出：单条或全部记录可导出为 Markdown 文件，也可复制、转发到你选择的应用。
  • 删除：可删除单条记录；设置页提供「清除本机全部数据」，一次性删除记录、待办、摘要、 录音文件与接口配置。
  • 撤回授权：可在系统设置中随时关闭麦克风、日历等权限。

由于数据保存在你的设备上，我们无法远程查看或替你删除；删除操作需要你在应用内完成。

七、未成年人

草记面向成年人与职场使用者，不面向 14 周岁以下儿童。若你是未成年人，请在监护人指导下使用， 并由监护人阅读本政策。

八、政策更新

功能或合规要求变化时，我们可能更新本政策。更新后会在应用内以弹窗或设置页说明的方式提示， 并在本页面更新「生效日期」。若你不同意更新内容，可停止使用并卸载应用。

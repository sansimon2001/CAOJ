# 草记 · PC 端

手机端录不到的东西，这里能录。

腾讯会议、飞书会议、Zoom、微信语音、网课 —— 这些声音从扬声器出来，手机没有权限去采，
行业里所有录音 App 在安卓和 iOS 上都做不到。PC 端走 WASAPI 回环，可以直接把系统输出的声音录下来，
还能和麦克风混成一条轨，线上会议双方都清楚。

**这个能力已实测验证，不是假设。** 见 [`spike/`](spike/README.md)：程序自己播一个 1 kHz 正弦波，
再从回环录回来分析频谱 —— 基线能量 0，信号期峰值 255（满量程）。同一套代码录静音时 RMS 是
0.000005、峰值 0，说明拿到的不是一段静音空包。

## 二、怎么跑起来

```bash
cd pc
npm install

# 开发（带热更新）
npm run dev

# 生产模式：编译主进程 + 打包前端 + 启动
npm start

# 只重新构建
npm run build
```

> 如果启动时报 `Cannot read properties of undefined (reading 'commandLine')`，
> 说明环境里被注入了 `ELECTRON_RUN_AS_NODE=1`，Electron 退化成了纯 Node。
> `tools/launch.js` 已经处理了这种情况，直接用 `npm start` 即可；
> 自己写命令启动时才需要 `env -u ELECTRON_RUN_AS_NODE -u NODE_OPTIONS`。

### 技术栈

| 项 | 值 |
|---|---|
| 外壳 | Electron 31 |
| 渲染层 | React 19 + TypeScript + Vite |
| 录音 | Web Audio + MediaRecorder（Opus 64 kbps） |
| 转写与摘要 | 直连 HTTP，无中间服务 |

## 三、填一次 Key 就能用

打开「设置」，转写和大模型各选一家。地址与模型名已按服务商预填好，通常**只需要填 Key**。
默认是硅基流动：转写与摘要同一家、同一套 Key，注册送额度。

| 环节 | 推荐服务 | 说明 |
|---|---|---|
| 转写 | 硅基流动 SenseVoice | 便宜、中文好；只返回纯文本 |
| 转写 | Groq Whisper large-v3 | 最准，远场与口音场景错字明显更少；需能访问境外服务 |
| 摘要 | 硅基流动 Qwen2.5-7B | 与转写同一套 Key，最省事 |
| 摘要 | 智谱 glm-4-flash | 目前可免费调用 |

填完点「测试连接」，会真的发一次最小请求 —— 成功会回显模型说的话，
失败会明确告诉你是 Key 无效、地址不对还是额度用尽。

Key 存在本机，落盘前用系统级加密（Windows 走 DPAPI），换机器要重填。

## 四、录音怎么选音源

| 音源 | 适合 | 说明 |
|---|---|---|
| 麦克风 | 线下见面、当面沟通 | 普通采集 |
| 系统声音 | 腾讯会议 / 飞书 / 微信语音 / 网课 | WASAPI 回环，电脑在放什么就录什么 |
| 两者都录 | 线上会议 | 你的声音走麦克风，对方的声音走回环，混成一条轨 |

混音时麦克风开了回声消除：系统声音已经由回环单独录了一份，如果麦克风再把扬声器漏出来的声音
收进来，同一句话会出现两遍还带时间差。

**系统声音录不到内容时先查三件事**：声卡在不在放声音、系统音量是否为 0、有没有插着耳机但
播放设备选的是另一个。回环采的是「默认输出设备」，设备不对时录到的就是静音。

## 五、数据在哪

```
%APPDATA%/caoji-pc/
├── settings.json          配置（Key 已加密）
└── data/
    ├── records/<id>.json  一条记录一个文件
    └── audio/<id>.webm    对应音频
```

设置页有「打开数据目录」。整个 `data/` 拷走就是完整备份，换机器放回同一位置即可。

选这个存法而不是 SQLite，是因为逐条写文件不会出现「写到一半断电，整个库都坏了」，
单条损坏最多损失一条。记录量到几千条时再换库也不迟，结构已经是平的。

## 七、怎么验证它真的在工作

三个脚本，都在页面上下文里跑，由环境变量注入：

```bash
# 1) 可行性：播 1kHz，再从回环录回来分析频谱
npm run spike

# 2) 录音链路：自动点开始、录 4 秒、点结束，核对记录是否落盘
CAOJI_E2E="$(pwd)/tools/e2e-record.js" node tools/launch.js

# 3) 解码核对：把录到的 webm 真解码，算 RMS 与峰值（判断是不是静音空包）
CAOJI_E2E="$(pwd)/tools/e2e-decode.js" node tools/launch.js
```

AI 链路可以用本地模拟服务验证协议与守卫，不需要真 Key：

```bash
node tools/mock-ai.js &
CAOJI_E2E="$(pwd)/tools/e2e-ai.js" node tools/launch.js
```

模拟服务故意返回「摘要里的数字原文没有 + 一条编造的待办」，
正确的表现是：数字被点名、编造的待办被丢掉、记录标记为需人工确认。

另外 `CAOJI_SHOT=<png 路径>` 可以让程序加载完界面后自动截图再退出，改样式时省得每次手点。

## 八、已知限制

- **没有安装包**。要从源码跑（`npm start`）。要发给别人用，还需要接 electron-builder 出 exe。
- **方言受服务端限制**。粤语 SenseVoice 原生支持；吴语、闽南语、客家话等在 Whisper 协议里
  没有对应语言代码，只能按普通话送，App 不会假装支持。
- **说话人分离依赖服务端**。SenseVoice 与 OpenAI whisper-1 都只返回纯文本，
  所以第一版没有做「我 / 对方」的区分。要这个能力需自建 faster-whisper / whisperX。
- **系统声音需要默认输出设备在放声音**。用独占模式的播放器（部分专业音频软件）时可能采不到。
- **录音没有做静音检测**。手机端有「连续 10 秒振幅为 0 判静音」，PC 端第一版没有，
  录一场没人说话的会照常保存。

## 九、合规

录音涉及他人声音。会议录音前请告知参会人，仅作个人工作记录使用，
不要用于非法目的或公开传播。系统内录同样受此约束 —— 能录不代表可以随便录。

这是「草记」交互原型

可点击操作：切 Tab、点记录看详情、勾待办、开始/结束记录、标记重点、切换耳机连接。

核心的逻辑

  • 持续记录 → 自动转写 → 拆分事件、生成标题与摘要
  • 「今日」看结构化摘要与待办，「项目」跨场景归集，「觉察」看行为洞察
  • 短按标记重点；默认只留文字不留原音

按你要求改的两点

  • 触发：连上蓝牙耳机才开始记录，断开自动结束（右上角可点「耳机未连接」模拟连接）
  • 音源：也可手动选手机麦克风直接录（今日页底部「音源」），录音中途切换也是立即生效
  • 通话：读取手机自带通话录音文件纳入记录

中国方言与多语言（v1.19 新增）

  • 设置页新增识别语言与方言：普通话 / 粤语 / 吴语 / 闽南语 / 客家话 / 湘语 / 晋语 / 四川话 / 东北话 / 中英混合 / 英日韩
  • 能不能真的识别，取决于服务端有没有那个方言的模型——粤语 SenseVoice 原生支持；其余方言会按普通话识别，设置页当场写明，不假装支持
  • 方言稿可自动转成普通话书面语（多花一次大模型调用），原话完整保留，详情页一键切回
  • 本地会检测「选了普通话、文本却满是粤语用字」的情况，直接给「按粤语重转」入口（见「昨天」那条粤语记录）
  • 支持提示词的服务可填热词表（人名 / 公司 / 术语），方言录音里专名最不容易错

项目归属：不再记错项目（v1.20 新增）

  • 项目从「一串名字」升级成档案：规范名 + 别名 + 线索词 + 说明，分析时只把相关候选连特征一起给模型
  • 历史碎片自动归并：「城市之光」「城市之光项目」「城市之光 」从此是同一条线，不再各挂一半记录
  • 强制模型抄原文依据：抄不出证据就必须留空——「空」比「错」有用，错归会让你以后彻底找不到这条记录
  • 拿不准的标「待确认」（列表标签带 ?），详情页点项目条就能改，改完记进档案，下次同类说法自动命中
  • 一次会议跨项目时，每条待办自带项目标签，不会把 A 的报价算成 B 的
  • 项目页顶部会提示「有 N 条记录还没归属」，点进去逐条归类
  • 点开「虞懋府 3 号楼」（已确认）、「陈师傅睇楼」（待确认）、「退租原因标签」（未归属）三条，能看到三种状态的差别

AI 服务商：可选免费的

  • 智谱 glm-4-flash：目前可免费调用，日常摘要够用
  • 通义千问 qwen-turbo：新用户每模型有免费额度
  • 硅基流动：注册送额度，转写也在这家，一套 Key 全搞定
  • DeepSeek：无免费但极便宜（百万 token 约 1~2 元）
  • 设置页选服务商 → 地址与模型自动填好，只需填 Key，还能一键测试连接

技术边界（必须知道）

  • 来电/去电：可覆盖（依赖系统通话自动录音，ColorOS 支持）
  • 微信语音：无法覆盖——微信语音不走系统通话通道且会静音内录，第三方 App 与录音笔都做不到

功能一览

  • 自动记录 → ✅ 连蓝牙耳机触发（你的要求）
  • 隐私灯 → ✅ 常驻通知 + 状态条
  • 短按打标 → ✅ 记录时间点，列表显示「重点 N」
  • 长按语音输入 / 即时问答 → ✅ 点左下「按住说话」试试
  • 转写 + 摘要 + 待办 → ✅ 云端 AI（可选免费模型）
  • 「今日」时间线 → ✅
  • 「项目」归集 + 洞见卡片 → ✅ 点「项目」里的条目看
  • 「觉察」+ 跨记录复盘 → ✅ 见觉察页「生成复盘报告」
  • 只留文字不留原音 → ✅ 可设置保留
  • 通话内容 → ⚠️ 读系统通话录音
  • 微信语音 → ❌ 系统限制，第三方做不到

上一轮新增（1 + 2）

  • ① 声纹区分我/对方：转写后文本变成 [我] / [对方] 分角色格式，摘要按角色归纳——点开第一条记录看「原始转写」
  • ③ 本人声纹（新增）：录一次自己 15 秒的声音，之后自动认出哪几段是你说的话，详情页显示「我 = 说话人1（匹配度 98%）」——见「设置」页与任意记录详情
  • ② 待办到期提醒：待办自动带到期日（「下周五」自动换算日期），详情页点日期可手改；每天定时提醒今天到期/已逾期，觉察页顶部也有提示
